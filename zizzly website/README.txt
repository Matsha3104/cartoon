# Zizzly Website Prototype

A responsive multi-page website inspired by the supplied PowerPoint screenshots.

## Pages
- `index.html` — Home
- `about.html` — About Zizzly
- `events.html` — Events
- `products.html` — Product showcase
- `activities.html` — Children's activities
- `shots.html` — Photo gallery
- `designers.html` — Design approach/team
- `services.html` — Services
- `signup.html` — Sign-up form mock-up
- `login.html` — Login form mock-up

## How to run
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. The shared stylesheet is `css/style.css`; the small navigation/form script is `js/main.js`.

## Notes
- The design uses a playful blue, yellow and white palette based on the reference screenshots.
- A few gallery/hero photographs load from Unsplash, so internet access is needed for those images.
- Forms are front-end demonstrations only. They do not store information or authenticate users.
- Replace sample event dates, product prices and gallery photographs with approved, accurate content before publishing.
